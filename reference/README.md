# Approved frontend reference

`Rovei_APPROVED_FINAL_FRONTEND.html` is the final approved integrated visual prototype from the pre-backend phase.

It is **reference material**, not the production architecture. The Next.js application under `src/` is the production codebase we will extend.

During the GitHub/backend migration:

- preserve the approved landing-page composition, motion and palette;
- preserve the final Studio theme behaviour, first-run tour, international timezone behaviour and settings visual direction;
- do not silently redesign approved screens;
- move browser-only persistence to the backend in staged migrations rather than deleting working frontend behaviour all at once.
